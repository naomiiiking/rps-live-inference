# Rock Paper Scissors game

![Demo](thumbnail.png)

An extension of the [training pipline](https://github.com/naomiiiking/paper-scissors-rock-classifier) for a RPS Vision classifier model.

```bash
uv run main.py | rps-classifier-finetuned ## Run the original/finetuned model in evaluation mode
uv run game.py ## Play the game with the finetuned model
```
